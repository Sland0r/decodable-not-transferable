TL;DR

Latent action models do carry action information, and a probe can read it out inside games it was trained on. But that mapping does not carry over to new games. The strongest action signal comes from a generic video tokenizer, not from either latent action model.

SetupAre latent actions really primitives?

A latent action model squeezes the change between two frames into a small vector that stands in for the missing action. If these latents are true action primitives, move left should mean the same thing in every game.

We freeze each encoder and train small probes on its latents to predict the action: linear (MLP-0) or an MLP with 1–2 hidden layers. To measure transfer, 39 of the 193 games are held out entirely. As a control, null transitions (two identical frames) show how much accuracy comes from things other than the action.

Datasets

Retro · our corpus

We collected 193 2D platformers using Stable Retro: 98 NES, 63 SNES, 24 Master System, 7 Game Boy and 1 Atari 2600 title. Each game has 20 rollouts of 4,000 steps from a scripted controller. The task is a 4-way classification over right, left, crouch and jump.

Open Pixels2Play · P2P subset

Gameplay video from 3D games with keyboard labels. Several keys can be held at once, so the task is multi-label over 10 keys. We use the 291 sessions captured at 640×480 and split them 80/20. VideoFlexTok is not evaluated here because it needs multi-frame clips.

Q1How is action information encoded?

Present, but weak The signal is real, but it is a thin residual on top of a description of the scene.

30% → 45–66%
The signal is real. Null-transition latents sit at the majority baseline (~30%) at every probe depth, while game identity stays at 98.7–99.2%. Real latents beat the floor for all three encoders.
4 / 32
Latents describe the scene. Four dimensions carry 99% of AdaWorld's variance (16 of 32 for Olaf-World). A real transition adds only two or three directions on top.
F ≤ 0.4
No axis separates actions. F is the Fisher score: between-class over within-class variance of the best single coordinate. F ≫ 1 would mean a separating axis. Action centroids sit closer together (0.22–0.43) than two samples differing only in action (0.80–1.07).

Is the action just hidden in superposition?

Maybe the information is there but spread over many dimensions. We trained top-k sparse autoencoders (SAEs) on the latents and looked for single features that select for actions, with game identity as a positive control.

Q2Is it decodable in a known environment?

Yes Probes clear the baseline for every encoder and deeper probes add 16–25 points, but this does not show a shared action code across games.

Averages hide big differences

Fitting one probe per game, accuracy ranges from that game's majority baseline up to 100%. On P2P, rare keys score near zero with a linear probe but improve with depth, so the information is there even when a linear probe misses it.

!

Pooled decoding ≠ a shared action code

Game identity is itself linearly decodable (75.8–99.2%), so a pooled probe can first work out which game it sees and then apply a game-specific rule. The latent space shows exactly this.

Q3Does the decoder transfer to unseen games?

Largely no The capacity that helps inside the training games hurts outside them: MLP-2 loses 30–33 points and ends up below the linear probe.

1

Depth learns game-specific rules

Linear → MLP-2 adds 16–26 points inside the training games and removes points on unseen ones. The MLP learns game-conditioned associations, not one rule that works everywhere.

2

The failure is broad, not outliers

Across the 39 held-out games the median is close to the mean and the distribution is not bimodal. The probe beats 85–95% of games' own majority class, so it carries some information, but it is no usable control signal.

3

Game dominates action

Same-action-different-game latents are farther apart than same-game-different-action ones: entanglement ratio 1.18 / 1.34 / 1.38 for AdaWorld / Olaf-World / VideoFlexTok.

TakeawaysWhat this means for latent actions

01

The atomic-action hypothesis holds within an environment, not across environments

All three representations contain an action signal (Q1), decodable wherever the probe has seen the environment (Q2). A single fitted latent-to-action mapping does not carry over to a new one (Q3). Action information is environment-specific.

02

Evaluate on held-out environments

Held-out samples from known environments overstate how transferable a representation is, and probe capacity makes it worse. A linear probe gives the more honest estimate.

03

Better decoding doesn't close the gap

Olaf-World beats AdaWorld on every probe, yet it has the higher entanglement ratio and the larger MLP-2 drop (−33.1 vs −30.3). The conclusion does not depend on which LAM is stronger.

04

The best action reader isn't a LAM

VideoFlexTok has no action objective, yet decodes Retro actions best at every probe depth. Objective, width, input window and data are confounded, so we report it as an observation. A natural next step: use its latents as a LAM's alignment target.

Limitations
  • Only two closely related LAMs (AdaWorld, Olaf-World), so conclusions are specific to them.
  • Video games only; whether this holds in other domains such as robotics is open.
  • A label like jump does not always produce the same visual transition across or within games, so each class mixes visual effects.
  • Default frame pairs use action-dependent spacing. The drop persists under a fixed-spacing control, but that control changes which pairs are evaluated.
